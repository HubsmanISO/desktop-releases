# Hubsman Desktop

Distribuciones oficiales de Hubsman para Windows.

Para instalar Hubsman desde el navegador en PC o celular, visita [app.hubsman.com/instalar](https://app.hubsman.com/instalar).

Los instaladores de Windows están disponibles en [Releases](https://github.com/HubsmanISO/desktop-releases/releases). Hubsman necesita conexión a internet y una cuenta con acceso.

Este repositorio solo distribuye instaladores e información de versiones. No contiene el código privado ni datos de clientes.

Soporte: soporte@hubsman.com.
